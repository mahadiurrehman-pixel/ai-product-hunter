# AI Product Hunter 🎯

AI-powered e-commerce product discovery and supplier matching platform. Find winning products on eBay and match them with suppliers on AliExpress.

## 🚀 Features

- **eBay Product Discovery**: Search and analyze eBay listings using official Browse API
- **Smart Product Matching**: Multi-stage matching engine with semantic similarity
- **Transparent Scoring**: Market signals, competition analysis, profit calculations
- **Opportunity Analysis**: Data-driven scoring with clear evidence and reasoning
- **Profit Calculator**: Detailed profit estimates with configurable marketplace fees
- **Watchlist**: Save and monitor promising product opportunities

## 📋 Requirements

- Python 3.10 or higher
- eBay Developer Account (for API credentials)
- 4GB RAM minimum
- 2GB disk space
